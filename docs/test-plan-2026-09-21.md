Traps that cost time today, so they do not cost it again:

- **The `.ps1` and `\r`**: the patch tool turned `maintenance\restart-tinycmdr.ps1` inside a
  PowerShell string into a real newline. Edit escape-heavy files with a Python script using raw
  strings, then parse-check the result (`[scriptblock]::Create`).
- **Line endings per file**: `tinycmdr.py`, the installers and the docs are not all the same
  (CRLF vs LF). A byte-level edit must convert its anchor to match the file it is editing.
- **`test_cli` grades the generated build**, so regenerate it BEFORE running the suite, or the
  suite grades yesterday's file.
- **A probe install must pass its own `-TaskName`** and unregister it; `-VerifyOnly` never reaches
  the installer's package-integrity check.
- **`/api/health` is deliberately open** (the supervisor's readiness gate polls it), so the token
  is graded on a protected endpoint: `/api/events` answers 401 without it, 404 with it.
