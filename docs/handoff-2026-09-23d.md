## 5. Traps this session paid for

```
- A Mattermost BAR post keeps its text in props.attachments and has message="".
  Reading only "message" misreported a live answer as an erased post - and the
  claim nearly shipped. Always fetch props.
- heredoc byte literals: the JSON decode halves backslashes - a b'... \\' anchor
  arrives as \' and python reads an unterminated string. Build backslashes with
  chr(92).
- The idle check: the log grows every 60s (the catch-up poll) - the RUN JOURNAL's
  mtime is the idleness signal, not the log's.
- A timing test needs a thread-start handshake; "blocked" alone passes for the
  wrong reason and flakes under sweep load.
- delta-equality newline checks are wrong for LF inserts into mixed files: compare
  added-crlf against the replacement's crlf, added-lf against its lf.
- test_stall subclasses MattermostDispatcher: it cannot run against the console
  build (AttributeError at import) - that is why it is not in the CLI spec list.
```
