## 6. Traps this session paid for

```
- PATH: native python cannot take ~/hermes-tmp/... (MSYS path) - use C:/Users/David
  Trapp/hermes-tmp/....
- The `patch` tool MANGLED tinycmdmdr.py's CRLF endings (955 insertions/485 deletions on a
  one-function edit). Edit this tree with byte-level replacements in python, and re-check
  `crlf == lf` counts before and after. Recovery is `git checkout -- tinycmdr.py`.
- `export TINYCMDR_SRC=...` PERSISTS between terminal calls in this session: a later "fixed
  build" run was silently testing the pre-fix build. Set it per command.
- A test handler that assigns `self.lock` shadows logging.Handler's own lock and
  self-deadlocks on the first record (non-reentrant). Name it something else.
- the other Windows box's supervisor-status.json goes stale while the child is alive-but-deaf: it is not a
  liveness signal. Read the log's growth and the child's start time.
```
