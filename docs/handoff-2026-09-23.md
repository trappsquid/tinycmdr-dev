Traps this session paid for (also written into the skill):

```
- a host-local fix is a FORK: .13's one-word comment change was the difference between a public
  build and a refusal, and the push would have reverted it. Diff a host's file against the tree
  before pushing, not after.
- the fleet kit can PREDATE an addition to SHIP: compare dist/<archive> mtime against the file's
  mtime before blaming an installer.
- read a bot's ACCOUNT off its own log (the other Windows box is @the other Windows boxnew now, the Windows test box is @bot-a) — a list of
  account names goes stale silently.
- polling a bot's log from the START re-reads megabytes: seek to the current size and read only
  what grows. A poll that shows nothing for 200s can simply be a long model call, not a wedge.
```
