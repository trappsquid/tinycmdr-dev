# The gate's own dependencies - not what a tinycmdr install needs.
#
# requirements.txt is what the bot runs on. This file is only for
# `python tests/run_all.py` on a dev box and for CI:
#
#     pip install -r requirements.txt -r requirements-test.txt
#
# requests / rich / prompt_toolkit come from requirements.txt: the suites import the
# tree's own tinycmdr.py, so anything it imports has to be there. The only suite that
# ever needed more of its own was the local web UI's browser suite, and that whole
# surface is gone, so there are no extra packages to install here any more.

# No pytest. Three suite docstrings used to advertise `python -m pytest -q <file>`;
# their check() only ever printed, so pytest collected no test and exited 0 with the
# failures sitting in the log (BUGREPORT T2). The suites are standalone scripts and
# tests/run_all.py is the runner that reads their exit codes.
