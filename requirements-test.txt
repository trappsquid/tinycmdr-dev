# requirements.txt is what the bot runs on. This file is only for
# `python tests/run_all.py` on a dev box and for CI:
#
#     pip install -r requirements.txt -r requirements-test.txt
#
# requests / rich / prompt_toolkit come from requirements.txt: the suites import the
# tree's own tinycmdr.py, so anything it imports has to be there.

# playwright is what tests/test_webui_browser.py drives. Without it (or without a
# browser) the suite exits 77 - SKIP - and run_all.py counts SKIP as RED, so install
# the browser with it:
#
#     python -m playwright install chromium
#     export TINYCMDR_TEST_BROWSER_CHANNEL=     # empty = playwright's own chromium
#
# (the suite defaults to the msedge channel, the browser the author's box has; CI
# installs the bundled chromium and clears the channel with that variable).
# tests/test_webui_page.py runs the page script under `node`, which a dev box needs
# on PATH; without it that suite also exits 77.
